# v1.0.0 — Public MVP and Release Hardening

This release turns World Cup Market Intelligence into a coherent public MVP.

v0.8.0 introduced catalyst notes and narrative intelligence.

## One-command project validation

Added:

- scripts/validate_project.py

The validation script performs safe local checks:

- no live API calls
- no full historical workflow
- no automated scraping
- required files check
- Python syntax checks
- catalyst notes validation
- catalyst sample validation
- provider validation when available
- generated output ignore checks
- dashboard content checks
- safe command help checks

Run:

- python scripts/validate_project.py

Expected result:

- Result: PASS

## Existing intelligence layers

v1.0.0 consolidates the previous intelligence layers.

### Catalyst notes

Main files:

- data/manual/catalyst_notes.csv
- examples/catalyst_notes_sample.csv
- src/wcmi/catalyst_notes.py
- scripts/validate_catalyst_notes.py
- scripts/match_catalyst_notes.py

Catalyst notes provide manual context for market movement.

They do not prove causality.

### Narrative intelligence

Main docs:

- docs/narrative_intelligence.md
- docs/catalyst_notes_workflow.md

Narrative intelligence connects market movement with possible real-world explanations.

It is manual-first and transparent.

### Team intelligence

Main files:

- scripts/generate_team_intelligence.py
- docs/team_intelligence.md

Generated output:

- data/processed/team_intelligence_latest.csv

Team intelligence aggregates signals and catalyst matches by team.

High review priority means manual research is recommended.

It does not mean a betting recommendation.

## Commands

Run safe validation:

- python scripts/project_health.py

Validate catalyst notes:

- python scripts/validate_catalyst_notes.py

Validate catalyst sample:

- python scripts/validate_catalyst_notes.py --path examples/catalyst_notes_sample.csv

Generate stable dashboard:

- python scripts/generate_dashboard.py

Generate trends dashboard:

- python scripts/generate_trends_dashboard.py

- python scripts/run_historical_trends_workflow.py
