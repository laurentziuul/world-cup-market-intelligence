\# v0.8.0 — Catalyst Notes and Narrative Intelligence



This release adds the first catalyst and narrative-intelligence layer to World Cup Market Intelligence.



The project can now connect probability movement and signal classification with manually curated catalyst notes.



This is an experimental research layer.



It is not betting advice.



\---



\## Summary



v0.8.0 introduces:



```text

manual catalyst notes

catalyst notes validation

catalyst-to-signal matching

historical workflow integration

catalyst matches in the trends dashboard

narrative intelligence documentation

```



This turns the project from a pure market-data and probability-movement tracker into a more contextual market-intelligence system.

\## Catalyst matching utility



Added:



```text

scripts/match\_catalyst\_notes.py

```



This script links catalyst notes to signal rows from:



```text

data/processed/signal\_summary\_latest.csv

```



and generates:



```text

data/processed/catalyst\_matches\_latest.csv

```



Matching logic uses:



```text

provider

team

market\_id when available

date lookback window

```



The default lookback window is:



```text

7 days

```

\## Why this matters



Before v0.8.0, the project could show:



```text

Germany moved +2.4 percentage points

liquidity increased

signal label = strong\_positive\_move

```



After v0.8.0, the project can also attach context:



```text

possible catalyst = strong group-stage result

confidence = medium

match type = team + date window

```



This creates a richer intelligence layer:



```text

market movement

liquidity context

signal classification

manual catalyst explanation

narrative interpretation

```

\## Design principles



The catalyst system is:



```text

manual-first

transparent

source-friendly

provider-agnostic

safe to publish

experimental

```



The catalyst system is not:



```text

an automated news scraper

a black-box prediction model

a betting system

a causal inference engine

```

\## Commands



Validate catalyst notes:



```powershell

python scripts/validate\_catalyst\_notes.py

```



Validate sample notes:



```powershell

python scripts/validate\_catalyst\_notes.py --path examples/catalyst\_notes\_sample.csv

```



Run catalyst matching manually:



```powershell

python scripts/match\_catalyst\_notes.py --provider polymarket --lookback-days 7 --include-unmatched

```



Run full historical workflow:



```powershell

python scripts/run\_historical\_trends\_workflow.py

```



Generate trends dashboard:



```powershell

python scripts/generate\_trends\_dashboard.py

```
