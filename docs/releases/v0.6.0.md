\# v0.6.0 Release Notes



World Cup Market Intelligence `v0.6.0` marks the first mature project structure milestone.



This version introduces a clear separation between:



```text

stable offline workflows

experimental live provider workflows

stable public dashboards

experimental public dashboards

provider documentation

safe generated-output handling

```



The project is still early, but `v0.6.0` establishes a clean foundation for future market intelligence features.



\---



\## Main theme



The main theme of `v0.6.0` is:



```text

stable core + experimental live intelligence

```



The project now has a stable reproducible layer and a separate experimental live market data layer.

\---



\## Polymarket YES-only ranking



`v0.6.0` includes a dedicated YES-only ranking for Polymarket World Cup winner markets.



It focuses on markets matching:



```text

Will X win the 2026 FIFA World Cup?

```



Only `Yes` outcomes are used for ranking.



This avoids the raw `No` outcomes dominating the table and gives a cleaner view of market-implied team probabilities.



\---



\## Generated output handling



Generated Polymarket outputs are ignored by default unless a version explicitly requires publishing them.



Ignored outputs include:



```text

data/raw/polymarket/

data/processed/polymarket/

data/processed/polymarket\_worldcup\_yes\_ranking.csv

data/processed/polymarket\_worldcup\_yes\_ranking\_summary.txt

data/processed/snapshots/\*-polymarket.csv

```



The separate Polymarket dashboard HTML can be committed when the goal is to publish the latest experimental dashboard to GitHub Pages.
