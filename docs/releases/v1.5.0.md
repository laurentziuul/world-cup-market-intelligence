## 6. Operator layer

v1.5.0 introduces 10 operator accounts as internal strategy profiles.

These are not real platform accounts. They are structured research personas used to test different decision rules against the intelligence system.

- operator_01_momentum: follows strong positive probability movement
- operator_02_liquidity_confirmed: acts only when probability move is supported by liquidity
- operator_03_catalyst_confirmed: acts only when a catalyst note matches the signal
- operator_04_contrarian: looks for market overreaction
- operator_05_top_teams_only: monitors only high-profile teams
- operator_06_volume_spike: follows unusual volume movement
- operator_07_high_review_priority: acts only on high team intelligence review priority
- operator_08_low_risk_watchlist: waits for confirmation before acting
- operator_09_human_discretionary: full manual review of all available context
- operator_10_no_trade_control: never acts, used as a control for comparison

Rules:

- paper mode is the default for all operators
- real mode is optional, small, manually reviewed and kept private
- no-trade is a valid decision and should be logged when relevant
- every decision must be logged before execution

## 7. Scheduler and daily pipeline

v1.5.0 includes Windows Task Scheduler support for daily pipeline automation.

The daily pipeline:

- takes a live Polymarket snapshot
- compares against the oldest available snapshot for maximum delta
- generates the trends dashboard
- generates the daily brief
- commits and pushes public outputs only

Scripts:

- scripts/run_daily_pipeline.ps1: main daily runner
- scripts/setup_task_scheduler.ps1: registers the task in Windows Task Scheduler

Setup (run once as Administrator):

```
.\scripts\setup_task_scheduler.ps1
```

Run manually at any time:

```
Start-ScheduledTask -TaskName "WorldCupMarketIntelligence-DailyPipeline"
```

Both scripts are ASCII-safe. Logs are written locally to logs/daily_pipeline.log and are not committed.

The scheduler is operational support, not decision automation. It prepares the data. The operator still decides.
