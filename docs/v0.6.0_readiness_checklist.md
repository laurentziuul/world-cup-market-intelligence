\# v0.6.0 Readiness Checklist



This checklist defines what must be true before World Cup Market Intelligence can be promoted to `v0.6.0`.



The goal of `v0.6.0` is not to make every provider stable.



The goal is to make the project structure mature enough to clearly support:



```text

stable offline workflows

experimental live provider workflows

separate public dashboards

clear provider documentation

safe generated-output handling

```

\## 8. Generated output handling



Generated Polymarket outputs should not be accidentally committed unless the version goal explicitly requires publishing them.



Ignored generated outputs include:



```text

data/raw/polymarket/

data/processed/polymarket/

data/processed/polymarket\_worldcup\_yes\_ranking.csv

data/processed/polymarket\_worldcup\_yes\_ranking\_summary.txt

data/processed/snapshots/\*-polymarket.csv

```



Relevant file:



```text

.gitignore

```



Status:



```text

required

```
