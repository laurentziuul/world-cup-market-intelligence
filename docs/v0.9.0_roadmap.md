# v0.9.0 Roadmap — Team Intelligence and Dashboard Usability

This roadmap defines the next development cycle after v0.8.0.

v0.8.0 introduced catalyst notes and narrative intelligence.

v0.9.0 focuses on making that intelligence easier to explore, filter and use.

Status: draft roadmap

## Main goal

The main goal of v0.9.0 is to turn the project from a data pipeline into a more usable intelligence product.

The user should be able to quickly answer:

- Which teams are moving?
- Which teams have catalyst context?
- Which signals are supported by liquidity?
- Which signals are unmatched by catalyst notes?
- Which teams deserve closer manual review?

## Product direction

v0.9.0 should improve:

- trends dashboard usability
- catalyst visibility
- team-level intelligence
- public presentation
- local research workflow

## What v0.9.0 should not do yet

v0.9.0 should not introduce:

- automated news scraping
- automated catalyst generation
- betting recommendations
- black-box model scoring
- complex UI framework
- database dependency

The project should remain simple, transparent and static-site friendly.

## Design principles

v0.9.0 should remain:

- manual-first
- transparent
- provider-agnostic
- easy to run locally
- safe to publish
- GitHub Pages compatible

## Public dashboard direction

The trends dashboard should become the main intelligence surface.

Current sections:

- Trend output status
- Top movers
- Signal summary
- Catalyst matches

Target v0.9.0 sections:

- Trend output status
- Team intelligence
- Top movers
- Signal summary
- Catalyst matches
- Manual review candidates

## Manual review candidates

A useful future section could highlight teams where:

- probability moved strongly
- liquidity increased
- catalyst note exists
- catalyst confidence is medium or high

Another useful section could highlight teams where:

- probability moved strongly
- no catalyst note exists yet

This helps guide manual research.

## Expected v0.9.0 outcome

By the end of v0.9.0, the project should have a clearer intelligence layer:

- market data shows current state
- historical trends show movement
- signal classification shows importance
- catalyst notes show possible explanations
- team intelligence shows where to focus attention
