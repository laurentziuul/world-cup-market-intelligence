# v0.9.0 — Team Intelligence and Dashboard Usability

This release adds the first team-level intelligence layer to World Cup Market Intelligence.

v0.9.0 builds on v0.8.0, which introduced catalyst notes and narrative intelligence.

The goal of this release is to make signals and catalyst context easier to explore by team.

This is an experimental research layer.

It is not betting advice.

---

## Summary

v0.9.0 introduces:

- v0.9.0 roadmap
- team intelligence summary generator
- generated output ignore rule
- team intelligence integration in the historical trends workflow
- Team intelligence section in the trends dashboard
- team intelligence documentation
- README update with v0.9.0 links
- v0.9.0 readiness checklist

This release moves the project closer to a usable public intelligence product.

## New team intelligence layer

Added:

- scripts/generate_team_intelligence.py

This script aggregates:

- signal rows
- catalyst matches

by team.

Input files:

- data/processed/signal_summary_latest.csv
- data/processed/catalyst_matches_latest.csv

Generated output:

- data/processed/team_intelligence_latest.csv

The output is generated and ignored by Git.

## Summary labels

The team intelligence generator creates simple rule-based labels such as:

- no_signals
- strong_signal_with_catalyst
- signal_with_catalyst
- strong_signal_needs_manual_review
- net_positive_attention
- net_negative_attention
- monitor

These labels are transparent and deterministic.

They are not machine-learning predictions.

---

## Review priority

The generator also creates a review_priority field:

- high
- medium
- low

High priority means the team deserves manual research.

It does not mean the team is a good bet or trade.

## Why this matters

Before v0.9.0, the project could show:

- individual probability movements
- top movers
- signal classifications
- catalyst matches

After v0.9.0, the project can also answer:

- Which teams deserve review first?
- Which teams have the most signal activity?
- Which teams have catalyst context?
- Which teams have unmatched signals?
- Which teams show positive or negative attention?

This makes the dashboard easier to scan and more useful for manual research.

---

## Design principles

The team intelligence layer is:

- simple
- transparent
- rule-based
- provider-aware
- static-site friendly
- compatible with GitHub Pages
- useful for manual review

The team intelligence layer is not:

- a betting model
- an investment system
- a black-box prediction engine
- a causal inference engine
- an automated news scraper
