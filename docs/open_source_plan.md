# Open Source Plan

## Repository positioning

World Cup Market Intelligence is an open-source event intelligence framework.

The FIFA World Cup 2026 implementation is the first case study.

## Public promise

> A transparent framework for tracking prediction-market prices, liquidity and narratives around scheduled global events.

## What makes it useful

- reproducible daily snapshots
- transparent scoring logic
- readable market briefs
- reusable architecture
- separation between data, narrative and inference
- red-team discipline

## Suggested GitHub description

`Open-source market intelligence framework for tracking prediction-market dynamics around FIFA World Cup 2026 and other scheduled global events.`
