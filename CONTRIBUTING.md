# Contributing

Contributions are welcome.

## Useful contribution areas

- Polymarket market discovery improvements
- World Cup schedule adapter
- signal scoring methodology
- dashboard exports
- tests
- documentation
- examples for other global events

## Rules

- Do not add trading automation.
- Do not add betting-tip language.
- Do not scrape copyrighted match footage.
- Keep source attribution clear.
- Separate data from interpretation.
