Prediction market intelligence for the 2026 FIFA World Cup

An open-source market intelligence framework for tracking prediction-market probabilities, liquidity, narratives, historical movement and future signal intelligence around the 2026 FIFA World Cup.

Stable

Manual CSV Dashboard

Stable, offline and reproducible dashboard generated from manually curated CSV data. This is the safe default workflow.

Open stable dashboard
Experimental live

Polymarket Live Dashboard

Experimental live dashboard using Polymarket Gamma API data and a YES-only World Cup winner ranking. This workflow depends on live API access.

Open Polymarket dashboard
Experimental intelligence

Historical Trends Dashboard

Experimental preview of probability movement, top movers and signal classification generated from historical prediction-market snapshots.

Open trends dashboard

Current architecture

  • manual_csv is the stable offline provider.
  • polymarket is the first experimental live provider.
  • The stable and experimental dashboards are intentionally separate.
  • The historical trends layer compares snapshots over time and extracts movement signals.
  • Live provider failures should not be treated as stable project failures.
