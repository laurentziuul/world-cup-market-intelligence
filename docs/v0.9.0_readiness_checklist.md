# v0.9.0 Readiness Checklist

This checklist verifies that the v0.9.0 team-intelligence and dashboard-usability release is ready.

Status: draft checklist

## Release scope

v0.9.0 includes:

- v0.9.0 roadmap
- team intelligence summary generator
- generated output ignore rule
- team intelligence integration in historical workflow
- Team intelligence section in the trends dashboard
- team intelligence documentation
- README update with v0.9.0 links

- docs/v0.9.0_roadmap.md
- scripts/generate_team_intelligence.py
