\# v0.7.0 Release Notes



World Cup Market Intelligence `v0.7.0` marks the historical trends and signal intelligence milestone.



This version moves the project beyond static snapshots and dashboards toward a system that can compare prediction-market data over time and surface early movement signals.



The project remains research-oriented and does not provide betting, trading or investment advice.



\---



\## Main theme



The main theme of `v0.7.0` is:



```text

historical trends + signal intelligence

```



The project can now support:



```text

snapshot comparison

probability deltas

top movers

signal summary

historical trends dashboard

```



\---



\## What v0.7.0 adds



`v0.7.0` introduces a historical trends layer.



The new layer can compare snapshots and answer questions such as:



```text

Which teams gained probability?

Which teams lost probability?

Which markets moved the most?

Which moves are supported by liquidity?

Which moves may be low-liquidity noise?
```

\## Snapshot comparison



New script:



```text

scripts/compare\_snapshots.py

```



Generated output:



```text

data/processed/snapshot\_comparison\_latest.csv

```



This compares the latest two processed snapshots for a provider.



It calculates:



```text

previous\_probability

current\_probability

probability\_change

probability\_change\_pp

previous\_volume

current\_volume

volume\_change

previous\_liquidity

current\_liquidity

liquidity\_change

```



The key metric is:



```text

probability\_change\_pp

```



This represents percentage-point change.



Example:



```text

0.15 → 0.17 = +2.00 pp

```

\## Signal summary



New script:



```text

scripts/generate\_signal\_summary.py

```



Generated output:



```text

data/processed/signal\_summary\_latest.csv

```



This classifies market movement using transparent rule-based logic.



Default signal rules:



```text

>= +2.00 pp         = strong\_positive\_move

+0.75 to +1.99 pp   = moderate\_positive\_move

\-0.74 to +0.74 pp   = flat\_no\_signal

\-0.75 to -1.99 pp   = moderate\_negative\_move

<= -2.00 pp         = strong\_negative\_move

```



Liquidity labels include:



```text

low\_liquidity\_noise

rising\_liquidity\_support

falling\_liquidity

normal\_liquidity

liquidity\_unknown

```



The signal system is intentionally simple and transparent.



It is not a black-box model.

\## Polymarket workflow integration



The Polymarket live workflow now supports optional trend generation.



Default command:



```powershell

python scripts/run\_polymarket\_live\_workflow.py

```



Optional trend command:



```powershell

python scripts/run\_polymarket\_live\_workflow.py --include-trends

```



The `--include-trends` option runs the historical trends workflow after generating the live Polymarket snapshot.



This requires at least two processed Polymarket snapshot CSV files.
