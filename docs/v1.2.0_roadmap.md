# v1.2.0 Roadmap — Final Polish and Portfolio-Ready MVP

This roadmap defines the final polish cycle for World Cup Market Intelligence.

v1.0.0 turned the project into a coherent public MVP.

v1.1.0 added data-quality, freshness and dashboard-trust layers.

v1.2.0 focuses on final presentation, demo readiness and portfolio polish.

Status: draft roadmap

## Main goal

The main goal of v1.2.0 is to make the project portfolio-ready.

A visitor should quickly understand:

- what the project does
- why it is useful
- how to view the public dashboards
- how to run local validation
- what is stable
- what is experimental
- why the project is research-only
- why this is a credible open-source proof-of-work project

## Product direction

v1.2.0 should improve:

- public presentation
- repo readability
- demo explanation
- final README polish
- final landing page polish
- validation confidence
- release closure

## What v1.2.0 should not do

v1.2.0 should not introduce major new features.

Do not add:

- new provider integrations
- complex UI framework
- database dependency
- automated news scraping
- AI prediction model
- betting recommendation system
- major architecture changes

This cycle is about polish, not expansion.

## Definition of done

v1.2.0 is done when:

- README is clear and polished
- landing page is demo-ready
- dashboards are linked and discoverable
- validation passes
- project health report runs
- trust layer works
- release notes exist
- demo guide exists
- final project summary exists
- tag v1.2.0 is pushed

## Final project positioning

World Cup Market Intelligence should be presented as:

- open-source market intelligence research
- FIFA World Cup 2026 prediction-market dashboard system
- transparent data pipeline
- static dashboard MVP
- catalyst and narrative intelligence experiment
- team-level intelligence layer
- trust and freshness-aware dashboard project
- Mayior Capital proof-of-work project

It should not be presented as:

- betting advice
- investment advice
- prediction engine
- trading bot
- guaranteed signal system
- black-box AI model

By the end of v1.2.0, the project should be ready to share publicly as a polished portfolio project.

- complete as an MVP
