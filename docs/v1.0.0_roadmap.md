# v1.0.0 Roadmap — Public MVP and Release Hardening

This roadmap defines the v1.0.0 development cycle for World Cup Market Intelligence.

v0.8.0 introduced catalyst notes and narrative intelligence.

v0.9.0 introduced team intelligence and improved dashboard usability.

v1.0.0 focuses on turning the project into a coherent public MVP.

Status: draft roadmap

## Main goal

The main goal of v1.0.0 is to make the project easy to understand, easy to run, easy to validate and credible as an open-source intelligence product.

By the end of v1.0.0, a new visitor should quickly understand:

- what the project does
- why it exists
- how to run it locally
- how the dashboards work
- what data is stable
- what data is experimental
- what is generated output
- why this is research, not betting advice

## Product direction

v1.0.0 should improve:

- public project presentation
- README clarity
- workflow reproducibility
- local validation
- dashboard polish
- release documentation
- first-time user onboarding

## What v1.0.0 should not do yet

v1.0.0 should not introduce:

- complex database dependency
- automated news scraping
- automated betting recommendations
- paid API dependency
- black-box AI prediction model
- complex frontend framework

The project should remain:

- simple
- transparent
- static-site friendly
- easy to run locally
- GitHub Pages compatible

## v1.0.0 definition of done

v1.0.0 is done when:

- README is clear for first-time visitors
- all major docs are linked
- all dashboards are discoverable
- validation script passes
- generated outputs are ignored correctly
- release notes exist
- readiness checklist exists
- public pages work
- tag v1.0.0 is pushed

## Public dashboard direction

The public MVP should present three dashboard layers:

- Stable dashboard: manual CSV, reproducible and safe
- Polymarket dashboard: experimental live provider
- Trends dashboard: historical signals, catalyst matches and team intelligence

## Research-only position

The project must remain clear that it is:

- market intelligence research
- educational
- open-source
- transparent
- experimental in live-provider sections

It is not:

- betting advice
- investment advice
- a prediction engine
- a trading bot
- a black-box model

## Expected v1.0.0 outcome

By the end of v1.0.0, World Cup Market Intelligence should feel like a real public MVP:

- understandable
- navigable
- documented
- reproducible
- visually presentable
- credible as an open-source research product
