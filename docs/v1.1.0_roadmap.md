# v1.1.0 Roadmap — Data Quality, Freshness and Trust Layer

This roadmap defines the v1.1.0 development cycle for World Cup Market Intelligence.

v1.0.0 turned the project into a coherent public MVP.

v1.1.0 focuses on trust, freshness, data quality and dashboard reliability.

Status: draft roadmap

## Main goal

The main goal of v1.1.0 is to make the public dashboards more trustworthy and easier to interpret.

A visitor should quickly understand:

- when the data was generated
- whether the data is fresh or stale
- which outputs are available
- which outputs are missing
- which provider is stable
- which provider is experimental
- whether the dashboard is safe to publish
- whether manual review is needed

## Product direction

v1.1.0 should improve:

- data freshness visibility
- generated output status
- dashboard trust indicators
- provider health reporting
- local validation quality
- public dashboard credibility

## What v1.1.0 should not do yet

v1.1.0 should not introduce:

- database dependency
- paid API dependency
- automated news scraping
- complex frontend framework
- black-box scoring
- betting recommendations

The project should remain:

- simple
- transparent
- static-site friendly
- GitHub Pages compatible
- easy to validate locally

## Why this matters

A public intelligence dashboard is only useful if users understand the reliability of the data.

A dashboard should clearly communicate:

- fresh data
- stale data
- missing data
- generated output status
- provider limitations
- experimental status

This protects the project from overclaiming.

It also makes the MVP more credible.

## Expected v1.1.0 outcome

By the end of v1.1.0, the project should have a clearer trust layer:

- validation shows project health
- dashboard shows output availability
- stale data is easier to identify
- provider status is easier to understand
- public viewers can interpret dashboards more safely
