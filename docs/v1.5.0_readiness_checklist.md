# v1.5.0 Readiness Checklist

This checklist verifies that the v1.5.0 Operator Validation / Live Research Layer is ready for release.

v1.5.0 moves the project from external product validation into internal operator testing.

The goal is to confirm that the intelligence system can support disciplined personal research decisions, with a clear separation between public methodology and private operational data.

The project remains research-only.

It is not betting advice.

It is not investment advice.

It is not financial advice.

It is not a prediction engine.

## 3. Private data safety

## 7. Not included in the public repository

The following must never be committed:

- Real-money decisions or live trade history
- Real PnL figures
- Active open positions
- Platform account IDs or usernames
- Wallet addresses
- API keys or tokens
- Screenshots containing balances or account information
- Private personal notes
- Private strategy sizing or bankroll information

Use aliases for any outreach or operator tracking data. Keep private research in data/private/ or a separate private repository.

---

## 8. Final release criteria

v1.5.0 is ready for release tag when:

- [ ] validate_project.py returns Result: PASS through .venv
- [ ] Git status is clean
- [ ] Private data safety is confirmed via git check-ignore
- [ ] Scheduler has been tested at least once manually
- [ ] v1.5.0 release notes are prepared: docs/releases/v1.5.0.md
- [ ] Git tag v1.5.0 is ready to be pushed after release notes are complete

Tag command (run after release notes):

```
git tag -a v1.5.0 -m "v1.5.0 - Operator Validation and Live Research Layer"
git push origin v1.5.0
```
